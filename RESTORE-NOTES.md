# Восстановление исходника живого сайта — 2026-07-04

## Зачем эта ветка
Живой сайт (linasia.shop, linasia.ru, www.linasia.ru) на момент 2026-07-04
работал из сборки, которой **не было ни в git, ни в исходниках на сервере**:

- ветка `main` собиралась в старый дизайн (без вкладок каталога, постер-баннера,
  «бумажной» темы и ambient-слоя);
- исходники на сервере `/var/www/lin-store/current/src` — версия от 2026-06-19,
  тоже старая;
- актуальный дизайн существовал только как **скомпилированный `dist`** на сервере
  (сборка от 2026-07-03 23:56), а также как копия в ветке `gh-pages`.

Sourcemap в сборке **отключён** (`vite.config.ts` без `build.sourcemap`), поэтому
восстановить оригинальные `.tsx` из минифицированного JS точно нельзя.

## Что здесь лежит
- `production-build/` — **точная живая сборка** (компилированная, деплоится как есть).
  Это то, что реально отдаётся на проде. Восстановимо/разворачивается напрямую.
- `recovered/site.css` — **полный CSS сайта, разложенный в читаемый вид** (без потерь,
  1:1 с проди). Это и есть редактируемый «исходник дизайна».
- `recovered/vendor-leaflet.css` — вендорный CSS (leaflet), для справки.
- `recovered/index.html` — HTML живого сайта.

## Структура дизайна (важно для будущих правок)
Живой CSS собран слоями:
1. Базовый слой (белая тема, `.hd`, `.card`, каталог) — близок к `main`.
2. Слой постер-баннера (`.catalog-banner*`, `.poster-*`).
3. «Бумажная» тема (`:root` с тёплой палитрой `--paper`, `--serif`) через `!important`.
4. Ambient-слой (`.ambient-layer`, падающие лепестки) с анимациями
   `petalFall`, `petalSway`, `softReveal`, `bannerBreath`, `inkPulse`.

Правки дизайна делаются добавлением/изменением слоёв в `recovered/site.css`,
затем CSS минифицируется и заменяет `assets/index-*.css` в сборке.
JS для чисто визуальных правок трогать не нужно.

## Ограничение
`.tsx`-исходник (логика компонентов) не восстановлен — только скомпилированный JS
в `production-build/`. Для полноценного возврата к редактируемым `.tsx` нужен
исходный проект с машины, где идёт сборка.
